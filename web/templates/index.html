      Deep Learning Architecture
      
About the BERT Fine-Tuning

      

        How Bidirectional Encoder Representations from Transformers (**BERT**) captures contextual threat semantics in social text.
      

    


    

      

        
🧠 Bidirectional Attention

        

          Unlike traditional recurrent networks (RNNs/LSTMs) that read text sequentially in one direction, BERT’s self-attention mechanism processes tokens bidirectionally simultaneously, capturing the surrounding context of every word.
        

      


      

        
🔤 WordPiece Tokenization

        

          Uses a 30,522-token vocabulary with subword segmenting. Slang, hashtags, and noisy repeated characters (e.g. heeeeyyy) are cleanly split into subwords without losing semantic representations.
        

      


      

        
🎯 Binary Classification Head

        

          The special [CLS] token representation at the final transformer encoder layer is passed into a dropout layer and linear classifier head configured for num_labels=2 (0: Normal, 1: Threat).

      Robustness Analysis
      
Outlier & Noise Testing

      

        Evaluating transformer resilience against intentionally noisy social-media formatting.
      

    


    

      

        
⚡ Injected Noise Patterns

        

          To mirror real-world social media volatility, 350 samples (3.5%) were injected with intentional artifacts:
        

        
    
          
  • • Excessive Punctuation: "!!!!!!!????????? $$$$$$"
    • 
          
  • • Repeated Words: "urgent urgent please please"
    • 
          
  • • Mixed Random Casing: "uRgEnT clAiM nOw"
    • 
          
  • • Vowel Stretching: "heeeeyyyy noooow"
    • 
          
  • • Malformed URLs & Emojis: "🚨🚨 #breaking http://xyz.win @admin"
    • 
          
  • • Extreme Text Lengths: Ultra-short & chained paragraphs

      Project Lifecycle
      
10-Step Development Workflow

      

        Systematic lifecycle from dataset engineering to web deployment.
      

    


    

      

        
STEP 01

        
Dataset Generation

        
10,000 synthetic posts with balanced classes and controlled outliers.

      

      

        
STEP 02

        
Preprocessing

        
Lightweight cleaning preserving punctuation and social formatting.

      

      

        
STEP 03

        
Stratified Splitting

        
70% Train, 15% Validation, 15% Test with fixed seed 42.

      

      

        
STEP 04

        
BERT Tokenization

        
WordPiece encoding with max sequence length of 128 tokens.

      

      

        
STEP 05

        
Model Training

        
AdamW optimizer, lr=2e-5, gradient accumulation, and mixed precision.

      

      

        
STEP 06

        
Model Validation

        
Evaluation after each epoch with automatic best checkpoint saving.

      

      

        
STEP 07

        
Test Evaluation

        
Rigorous metrics on 1,500 unseen held-out test posts.

      

      

        
STEP 08

        
Outlier Robustness

        
Separate performance validation on noisy social-media samples.

      

      

        
STEP 09

        
Real-Time Predictor

        
Standalone CLI and module inference pipeline for arbitrary text.

      

      

        
STEP 10

        
Web Application

        
FastAPI REST backend with modern cybersecurity web interface.
