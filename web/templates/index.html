About the Project

This project demonstrates a BERT-based binary text classification system for social-media threat intelligence. The model is trained to identify learned linguistic patterns associated with Normal and Threat posts.

The system was developed using externally collected publicly available datasets covering fake news, hate speech, spam, and normal social-media posts. These datasets were integrated and preprocessed before model training.

Class 0 Normal

Everyday discussions, friendly interactions, general opinions, hobbies, and benign online commentary.

Class 1 Threat

Threatening language, targeted harassment, coercive intimidation, scams, and dangerous content.

Important Note: The system is a classification prototype and does not independently verify whether a post is factually true or whether a person is actually dangerous.

Dataset & Data Processing

The dataset was collected from publicly available Kaggle datasets covering fake news, hate speech, spam, and normal social-media posts. The collected data were integrated, cleaned, preprocessed, and converted into a common binary classification format for the proposed BERT-based threat intelligence system.

1. Fake News

Used to represent misleading or potentially unreliable information.

2. Hate Speech

Used to represent hostile, abusive, discriminatory, or harmful textual content.

3. Spam

Used to represent suspicious promotional, scam-like, phishing-like, or unsolicited messages.

4. Normal Posts

Used to represent ordinary non-threatening social-media content such as casual conversations, daily activities, entertainment, sports, education, food, travel, hobbies, and general opinions.

Binary Label Mapping Architecture
Fake News + Hate Speech + Spam → Threat (Class 1)
Normal Social-Media Posts → Normal (Class 0)
Data Processing Pipeline

Public Dataset Collection → Dataset Integration → Data Cleaning → Duplicate Checking → Missing-Value Handling → Text Preprocessing → Label Mapping → Outlier Analysis → Train / Validation / Test Split → BERT Tokenization → BERT Fine-Tuning → Evaluation → ONNX Model Optimization → FastAPI Deployment → Web-Based Threat Analyzer

Outlier Analysis: Outlier analysis was performed on the collected dataset to identify unusual or noisy textual patterns, such as extremely short or long texts, repeated characters, excessive punctuation, and irregular social-media formatting.

How It Works

The inference pipeline processes each post through four sequential stages:

1

Enter Post

The user enters a social-media post into the web interface.

2

Tokenization

The text is converted into tokens using the BERT WordPiece tokenizer.

3

BERT Classification

The trained BERT model analyzes the text and predicts one of two classes.

4

Result

The system displays Normal or Threat along with the calibrated confidence.
