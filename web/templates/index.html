About the Project

This project is a threat-intelligence prototype that uses a fine-tuned BERT model to classify English social-media posts into two categories: Normal and Threat.

The Threat category covers patterns related to fake-news-like content, hate-speech-like content and spam/scam-like content.

Class 0 Normal — everyday discussions, casual conversations, benign commentary.
Class 1 Threat — suspicious, scam/phishing, hateful, or disinformation patterns.
Disclaimer: The model identifies linguistic patterns learned during training. It does not independently verify facts or determine whether a person is actually dangerous.
