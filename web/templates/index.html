OVERVIEW

About the Project

This project uses a fine-tuned BERT model to analyze English social-media posts and classify them as Normal or Threat. The system is designed as a threat-intelligence prototype that identifies learned linguistic patterns associated with potentially malicious or harmful social-media content.

🎯 Conceptual Threat Coverage

Threat-related patterns conceptually include fake-news-like content, hate-speech-like patterns, and spam/scam-like content.

Class 0 Normal

Everyday communication, benign expressions, news sharing, hobbies, and personal thoughts.

Class 1 Threat

Hostile harassment, fraudulent scam URLs, financial extortion, phishing, and toxic claims.

⚠️

Prototype Disclaimer: The system identifies learned linguistic patterns and does not independently verify whether a claim is factually true or whether a person is actually dangerous.
